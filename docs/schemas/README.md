# Schema Reference

This folder is the canonical reference for shared file and data formats in the LSPR Suite.

Current shared standards:

- `hdf_standard.md` - common HDF5 file principles and versioning rules
- `hdf_measurement_format.md` - spectroscopy measurement file layout
- `hdf_experiment_plan_format.md` - experiment-plan and pump-plan row conventions

App-specific schema docs should live under the relevant app architecture folder if they cannot be shared.
